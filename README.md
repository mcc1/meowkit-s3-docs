# meowkit-s3-docs

Public personal documentation mirror for MeowKit-S3. The source material is
vendor documentation, but this repository is maintained independently and is
not an official vendor release. The original upstream remote is kept as
`origin`; the personal GitHub mirror is `mcc1/meowkit-s3-docs`.

## Personal modifications

Personal notes and workflow changes are kept visibly separate from vendor
facts. In particular, local firmware builds, local installer usage, dependency
pins, and experimental firmware behavior belong to the firmware or installer
repository README files rather than being presented as official hardware
specifications.

When a vendor document conflicts with source code or a tested device, record the
discrepancy and identify which statement is authoritative. Do not silently
replace vendor specifications with unverified personal measurements.
