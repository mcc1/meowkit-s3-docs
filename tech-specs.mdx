# GPIO

1×16-pin (2.54 mm) Dupont female expansion header

![13 GPIO对齐](/images/13-GPIO对齐.png "13 GPIO对齐")

**External Power:**

  Pin 1: 3.3 V

  Pin 2: GND

  Pin 3: 5 V / VBUS

**I²C:**

  Pin 4: SDA (1 kΩ optional pull-up)

  Pin 5: SCL (1 kΩ optional pull-up)

**SPI:**

  Pin 6: CS0 (EXP\_IO2)

  Pin 7: MOSI (GPIO11)

  Pin 8: MISO (GPIO10)

  Pin 9: SCLK (GPIO9)

**Multi-function:**

  Pin 10: GPIO44

  Pin 11: GPIO12 / U

  Pin 12: GPIO17 / L /PWM

  Pin 13: GPIO18 / D / ADC

  Pin 14: GPIO8 / R / INT

Pin 15: RESET (hardware reset)

Pin 16: GND
